# 携程问道

酒店机票预订、行程规划与旅游攻略。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/ctrip-wendao#v1.0.3 --skill ctrip-wendao
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill ctrip-wendao
```

## 内容

技能正文在 `skills/ctrip-wendao/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/ctrip-wendao/payload/`，不要反向同步。版本以 git tag 为准。
